# Модуль LMS («Управление обучением»)

Клиентско-серверный модуль учебного портала: курсы, уроки, тесты, задания, форумы, календарь, оценки, уведомления и сопутствующая аналитика.

## Документация

**Техническая документация для разработчиков** находится в каталоге [docs/](docs/README.md): архитектура, модель данных, REST API, клиент, интеграция с ядром, эксплуатация и известные ограничения.

## Структура каталога (кратко)

- `api/` — Django-приложение `modules.lms.api`
- `client/` — Vue.js (маршруты, компоненты, `lmsApi`)
